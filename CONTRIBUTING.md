# Contributing

Documentation corrections, design proposals, issues and pull requests are accepted. There is no implemented plugin, supported release, package manager or build/test command yet. Planned behavior should not be reported as a working feature that regressed.

## Issues

The [issue chooser](https://github.com/Yivas/cotilleo-convo-opencode/issues/new/choose) has problem and proposal forms. A report should first be checked against [existing issues](https://github.com/Yivas/cotilleo-convo-opencode/issues), then identify the document or commit, relevant host and OS, reproduction, expected behavior and observed behavior. Proposals should explain a user task and a way to verify success without assuming Pi APIs exist in OpenCode.

Security-sensitive details use [SECURITY](SECURITY.md). Public submissions must exclude credentials, private prompts, conversations, personal paths, model configuration and sensitive logs.

## Pull requests

A [pull request](https://github.com/Yivas/cotilleo-convo-opencode/pulls) should address one coherent change and include its motivation, checks actually run, compatibility implications, risks and documentation impact. Product contracts need agreement before implementation. Submission is not permission to install packages, deploy services or access external resources.

Documentation can be verified by reading it and checking the affected links; no invented build commands or string-presence tests are expected. Checks not run or not applicable should be identified. No acceptance or review date is guaranteed.
