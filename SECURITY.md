# Security policy

## Supported lines

| Line | Status |
| --- | --- |
| Pre-development documentation on main | Reports about repository content are accepted |
| Released plugin versions | None; no plugin is implemented or supported yet |

No sandbox, permission enforcement or remote-control service is implemented here. Planned messaging must not be treated as approval to use tools or access another session, and cooperative reservations would not isolate shared applications.

## Reporting a concern

[GitHub private vulnerability reporting](https://github.com/Yivas/cotilleo-convo-opencode/security/advisories/new) is enabled for this repository. Security-sensitive details belong in that private form, not in a public issue or pull request. If the form is unavailable, a public issue may request a private contact without vulnerability details.

A report should include the file or commit, relevant OpenCode host and operating system, minimal sanitized reproduction, expected and observed behavior, impact and possible workaround. There are no supported plugin release numbers yet; a commit or document link identifies the affected content.

Credentials, tokens, personal paths, prompts, conversations, model configuration and other sessions' data must be removed. Reporting is not permission to access third-party resources or perform destructive testing.

Yivas will review the scope, ask for clarification when needed and coordinate a fix or disclosure as appropriate. No SLA, reward, CVE assignment or embargo is promised.
